# CODEMAP — куда что класть (актуально на 2026-09-21)

Краткий ориентир после появления `modules/` и `game_math.py`.
Перед правками читай также `README.md` и `TASKLIST.md`.

---

## Дерево (смысл)

```
main.py              — Telegram, callback’и, action_1/3/4, save/load
game_state.py        — состояние (inventory, equipment, karma, flags, AP…)
game_math.py         — урон, множители голода/жажды, AP по HP
location_stories.py  — сюжет 7 локаций + финалы
location_crafts.py   — крафт привязанный к локации
crafts.py            — глобальный крафт (факел и т.п.)
location_sources.py  — длинные канонические тексты L1–L6
keyboards.py         — клавиатуры
modules/
  hints.py           — всплывающие подсказки игроку
  (сюда же — расширения: лут, предметы, ловушки)
tests/               — только тесты, не в корень
TASKLIST.md          — текущие задачи
BASIS.md / README.md — архитектура и правила
```

## Что ты планируешь → куда класть

| Фича | Файл | Заметки |
|------|------|--------|
| **Лут по локациям + шансы** | `modules/finds.py` (новый) | Таблица `LOCATION_FINDS[loc_id] = [(item, weight), …]` + `roll_find(loc_id)`. Вызов из `main.py` → `action_1`. |
| **Свойства предметов** (съедобность, +голод/+жажда, описание) | `modules/items.py` (новый) | Один словарь `ITEMS["Ягода"] = {"hunger": 10, "thirst": 0, …}`. `use_consumable` в `main.py` читает отсюда. |
| **Новые крафты глобальные** | `crafts.py` | Как `craft_Факел`. |
| **Крафт только на локации** | `location_crafts.py` | `handle_craft_location_N_…`. |
| **Ловушки / животные** | `modules/traps.py` (новый) | Логика постановки/срабатывания; кнопки в `keyboards.py`; callback в `main.py`. |
| **Подсказки** | `modules/hints.py` | Уже есть (факел). |
| **Сюжет** | `location_stories.py` | Не смешивать с лутом. |
| **Математика выживания** | `game_math.py` | Урон, расход ресурсов — не дублировать в main. |
| **Тесты** | только `tests/` | Запрет мусора в корне (см. `.github/instructions`). |

Не создавай отдельную папку только ради лута — `modules/` уже для расширений.

## Замеченные несостыковки (не чинил)

1. **Факел:** в `modules/hints.py` рецепт «Ветка + Сухой мох», в `crafts.py` — «Спички + Ветка». Нужно выбрать один рецепт.
2. **Исследование** всё ещё, скорее всего, глобальный список в `main.py` (`action_1`) — локального лута пока нет.
3. **README** частично устарел: не описаны `modules/`, `game_math.py`, `TASKLIST.md`, `CODEMAP.md`.
4. **Сухпай / Ягода / Гриб** как еда: в `use_consumable` смотрится в основном ключ `"Еда"` — съедобный лут лучше завести через `modules/items.py`.
5. В корне лежит `__pycache__` — лучше не коммитить (уже в `.gitignore`, но blobs в дереве есть).

## Минимальный порядок внедрения лута

1. `modules/items.py` — каталог предметов + эффекты еды/воды.
2. `modules/finds.py` — таблицы находок по 7 локациям.
3. В `main.py` `action_1`: `from modules.finds import roll_find` → выдать предмет.
4. В `use_consumable`: брать hunger/thirst из `ITEMS`.
5. Строка в `TASKLIST.md` + при желании обновить README (раздел «Куда класть»).
