# Лесная игра (Forest Game)

Telegram-бот с текстовым survival-приключением: игрок проходит семь локаций, принимает сюжетные решения, собирает ресурсы, крафтит предметы и получает одну из семи концовок.

Проект рассчитан на Python 3.10+ и запускается как Telegram polling-worker.

### Ключевые правила игры

**Персонажи:**
- Главный герой начинает в лесу
- Компаньон — **только один кот**. Игрок дает ему имя в начале, кот проходит всю игру

**Структура:**
- 7 обработчиков локаций в `location_stories.py`
- 7 цепочек крафта в `location_crafts.py`
- состояние игрока, инвентарь, навигация, флаги сюжета и сохранение состояния
- четыре шкалы сюжетной кармы и резолвер семи финалов
- канонические тексты всех семи локаций встроены в код; L7 включает семь вариантов финала
- тесты для источников историй, сохранения состояния, концовок, сна и совместимости инвентаря

**Выживание и ресурсы:**
- Ресурсы редкие, но игрок должен иметь возможность выжить
- Опасности существуют (укусы, отравления и т.д.)
- Сложность сбалансирована: не слишком легко и не слишком жестоко

**Сюжет (приоритет #1):**
- Истории должны быть захватывающими, эмоциональными, душещипательными
- Несколько развязок, которые влияют на конец через систему кармы
- Изменение кармы явно прописывается в коде

**Боёвка:**
- PvP — полностью запрещено
- PvE — максимум 1–2 раза за всю игру, только если это усиливает историю

## 🎮 Архитектура системы

### Паттерн: "Fat Module, Thin Loader"
```
main.py (оркестратор) 
    ↓
game_state.py (центральное хранилище)
    ↓
location_stories.py (истории)
location_crafts.py (крафт)
keyboards.py (UI)
```

### GameState (центр системы)
Содержит состояние игры:

```python
inventory: Dict[str, int]          # Ресурсы и предметы
water_capacity: int = 5            # Лимит воды
food_capacity: int = 10            # Лимит еды
hp: int = 100                      # Здоровье
hunger: int = 50                   # Голод
thirst: int = 75                   # Жажда
equipment: Dict[str, str]          # Экипировка (head, chest, legs, hands, feet, back)
karma: Dict[str, int]              # 6 измерений кармы
story_state: str                   # Текущая фаза истории
current_location: str              # Текущая локация
 weather: str                       # Текущая погода
companion_name: str                # Имя кота
companion_status: str              # Статус кота
ap: int = 5                        # Действия в день
day: int = 1                       # Текущий день
```

### Система кармы (6 измерений)
Влияет на развитие истории и финальные концовки:

| Измерение | За что | Противоположность |
|-----------|--------|------------------|
| **heroic** | Смелые решения | — |
| **brutal** | Жёсткие подходы | gentle |
| **gentle** | Мягкие моменты | brutal |
| **clever** | Хитрость, смекалка | — |
| **reckless** | Безрассудство | — |
| **mysterious** | Таинственные события | — |

## 💡 КЛЮЧЕВЫЕ СОВЕТЫ ДЛЯ РАЗРАБОТКИ

### Как добавить новую ветку истории

1. **Отредактируй `location_stories.py`**
   ```python
   def handle_location_X(data, game, uid):
       if data == "branch_name":
           # Измени карму
           game.karma["heroic"] += 1
           # Измени инвентарь
           game.inventory["Вода"] += 2
           # Текст истории
           text = "Ты видишь..."
           # Клавиатура для следующего шага
           kb = next_kb
           return (text, kb)
   ```

2. **Добавь обработчик в `main.py`**
   ```python
   elif data.startswith("location_X_"):
       text, kb = handle_location_X(data, game, uid)
   ```

### Как добавить новый крафт

1. **Отредактируй `location_crafts.py`**
   ```python
   def craft_ItemName(game, uid):
       # Проверь ресурсы
       if game.inventory.get("Ветка", 0) >= 1:
           # Убери ресурсы
           game.inventory["Ветка"] -= 1
           # Добавь результат
           game.inventory["Факел"] = game.inventory.get("Факел", 0) + 1
           return ("Успешно! Ты скрафтил факел!", kb)
       return ("Недостаточно ресурсов!", kb)
   ```

2. **Вызови из `handle_craft()`**
   ```python
   if data == "craft_torch":
       return craft_ItemName(game, uid)
   ```
