# Лесная игра (Forest Game / LesSurvivalBot)

Telegram-бот: survival, 7 локаций, сюжет, карма, 7 концовок.
Python 3.10+, aiogram, polling.

## ГЛАВНАЯ ИНСТРУКЦИЯ ДЛЯ РАЗРАБОТКИ (и для AI)

### Жёсткие правила — не ломать проект

1. **Источник правды по еде, готовке, ловушкам и луту исследования** — согласованный дизайн (файл `еда.txt` у автора) и код в `modules/`. Не выдумывать новые блюда, ягоды, грибы, животных и шансы «для красоты».
2. **Не создавать файлы**, которых нет в таблице «Куда класть». Нет `modules/locations.py`, `modules/quests.py`, `modules/crafting.py`.
3. **Одна система готовки** — только `modules/cooking.py`. Словарь `CAMPFIRE_RECIPES` в `main.py` **удалён и не возвращать**.
4. **Тесты** — только в `tests/`. Не класть `test_*.py` в корень.
5. **Перед большим рефакторингом** — перечитай этот README и существующие modules. Не циклически перечитывать один `main.py` часами.
6. **Windows / PowerShell:** глобального `python` может не быть в PATH. Запуск только через venv и оператор `&` (см. раздел «Запуск»).

### Что уже есть в проекте

- 7 локаций, сюжет, крафт, карма, 7 финалов
- `modules/items.py` — реестр предметов (ягоды/грибы по регионам, блюда, ресурсы)
- `modules/cooking.py` — готовка на костре (кора, вода 0–3, теги ягоды/грибы)

- `modules/hints.py` — подсказки
- Mongo + in-memory fallback, тесты в `tests/`

**Персонажи:** один кот-компаньон, имя в начале.

**Выживание:** ресурсы ограничены, выжить можно; без PvP; PvE редко и только ради сюжета.

**Сюжет — приоритет:** эмоциональные ветки, карма влияет на финал.

## Архитектура: Fat Module, Thin Loader

```
main.py          — Telegram, callback’и, тонкий вызов modules
game_state.py    — состояние, save/load
game_math.py     — урон, голод/жажда, AP
location_stories.py / location_crafts.py / crafts.py / keyboards.py
```

`main.py` не должен снова содержать таблицы еды и рецептов — только вызовы `cook_item`, `roll_find`, `process_trap_rollover`.

## Еда, готовка, ловушки, исследование (актуально)

### Готовка (`modules/cooking.py`)

- На все рецепты нужна **1× Кусок коры**.
- Вода из **фляги** (`flask_water`): **0** (сухая обжарка), **1–2** (простая варка), **3** (сытная).
- Теги: любая **ягода** из `BERRY_ITEMS`, любой **гриб** из `MUSHROOM_ITEMS`.
- Блюда: Печёные ягоды, Жареные грибы, Мясо на коре, Ягодный отвар, Грибная похлёбка, Охотничья похлёбка, Лесная тушёнка.

### Ягоды и грибы (`modules/items.py`)

Ягоды: Лесная, Красная, Фиолетовая, Болотная, Горная.  
Грибы: Лесной, Дикий, Болотный, Пещерный, Горный.  
Не возвращать старые имена вроде «Лисичка / Мухомор» как основной лут и не плодить «Сырая рыба» без дизайна.

### Ловушки (`modules/traps.py`)

- Разблокировка с **L4** (Просека Охотников); после этого — на L1–L7, по одной на локацию.
- После **сна**: **40%** ломка без добычи, **60%** успех + лут из `TRAP_LOOT_TABLE`.

### Исследование (`modules/finds.py` → `action_1`)

Свой основной пул на каждую локацию L1–L7; отдельно бонусный бросок (кора; на L3 ещё глина).

### Заметка для AI / доработки

Сырые ягоды/грибы при кнопке «использовать» могут ещё не полностью читаться через `get_item_effects` — **не выдумывать** вторую систему еды в `main.py`; при доработке — `modules/items.py` + один вызов effects в `use_consumable`.

## Запуск (Windows / PowerShell)

Глобальный `python` часто **не в PATH**. Интерпретатор проекта:

` .\.venv\Scripts\python.exe `

В PowerShell путь в кавычках запускается через **`&`**. Не использовать bash (`&&`, `export`).

```powershell
# Активация venv (по желанию)
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
& ".\.venv\Scripts\Activate.ps1"

# Проверка синтаксиса и modules
& ".\.venv\Scripts\python.exe" -m py_compile main.py
& ".\.venv\Scripts\python.exe" -c "from modules import items, cooking, traps, finds; print(len(cooking.COOKING_RECIPES), items.BERRY_ITEMS[0])"

# Тесты
& ".\.venv\Scripts\python.exe" -m pytest tests/ -v

# Бот (нужен TOKEN в .env или в окружении)
& ".\.venv\Scripts\python.exe" main.py
```

Ожидаемый вывод проверки modules: `7 Лесная ягода`.

Установка зависимостей (один раз):

```powershell
& ".\.venv\Scripts\python.exe" -m pip install -r requirements.txt
```
